本集讲解临时 CUE、Memory CUE 与 Hot CUE 三种 CUE 点的定义、区别及设置方法。

## 核心概念

*   **CUE 点**：指曲目播放的起始位置标记。
*   **临时 CUE**：对应波形图下方的橙色三角形标记，代表当前设定的播放起点。
*   **Memory CUE**：静态预设 CUE 点，用于在曲目停止状态下快速调取特定位置。
*   **Hot CUE**：动态预设 CUE 点，通过打击垫控制，支持在播放或停止状态下即时跳转。

## 功能对比与操作

### 1. 临时 CUE
*   **功能**：作为默认的播放起始点。
*   **操作**：
    *   按下 Play 键或长按 CUE 键，曲目从临时 CUE 点开始播放。
    *   曲目播放时按下 CUE 键，指针返回临时 CUE 点。
    *   曲目暂停时，在任意位置按下 CUE 键，将当前位置设为新的临时 CUE。

### 2. Memory CUE
*   **特性**：静态 CUE 点，仅在曲目**停止**状态下可用；播放状态下无法调取。
*   **调取方法**：曲目停止时，通过 Deck 上方的左右导航按钮，在已存储的 Memory CUE 与临时 CUE 之间切换，随后按 Play 键播放。
*   **设置步骤**：
    1.  确保 **Quantize**（量化）功能已开启（指示灯为红色），以保证 CUE 点精准落在节拍线上。
    2.  通过 Jog wheel 或鼠标将指针移至目标位置。
    3.  按下 CUE 键，将该位置设为临时 CUE。
    4.  按住 **Shift** 键并点击方向**右**按钮，将当前临时 CUE 保存为 Memory CUE。

### 3. Hot CUE
*   **特性**：动态 CUE 点，通过 8 个功能打击垫控制。无论曲目处于播放或停止状态，按下对应打击垫即可立即从该点播放。
*   **用途**：既可用于接歌起始，也可用于在播放过程中切换曲目段落。
*   **设置步骤**：
    1.  在功能打击垫区域选择 Hot CUE 模式。
    2.  将指针移至目标位置（播放或停止状态均可）。
    3.  直接按下任意一个空闲的 Hot CUE 打击垫，完成设置。

## 注意事项

*   **设备兼容性**：老版本 CDJ 或 XDJ 设备可能无专用 Hot CUE 按键，且屏幕仅支持显示 3 个 Hot CUE 点，操作时需留意设备限制。
*   **量化设置**：设置 Memory CUE 前务必开启 Quantize，避免节奏偏差。
