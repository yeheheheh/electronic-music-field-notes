Drop 切 Drop 是一种在保持高能量层级的同时，通过控制后手曲目能量略低于前手，以符合听众体力与注意力变化的接歌技巧。

### 核心概念

*   **能量层级控制**：课程建议后手 Drop 的能量略低于前手 Drop。前手 Drop 结束后，听众处于“蹦累了”的状态，需要稍作休息但仍有“回光返照”的兴奋感。若后手能量过高，会造成不适；若能量过低，则无法维持舞池热度。
*   **风格转换策略**：若前手为 Progressive House 等以鲜明旋律为主奏的曲目，后手可选择弱化旋律、以鼓点律动为主的 Drop，以实现能量的平滑过渡。

### 操作步骤

1.  **切入时机**：在前手乐曲 Drop 高潮结束后，直接切入后手乐曲的 Drop 高潮部分。
2.  **保留 Outro**：建议保留前手乐曲的 Outro 部分，直到其完全结束后再将前手曲目撤出（Fade out/Cut），以增强两首乐曲之间的连续感。
3.  **Pre-drop 前置**：若后手曲目在 Drop 前存在 Pre-drop 段落，可将其提前接入前手乐曲中，作为过渡铺垫。

### 演示案例

*   **曲目组合**：前手 *Animals*，后手 *The Club*。
*   **操作要点**：在 *Animals* 的 Drop 结束后切入 *The Club* 的 Drop，并保留 *Animals* 的 Outro 直至结束。
