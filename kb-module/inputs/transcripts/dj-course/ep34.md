Drop 接 Intro 是一种在曲目高潮（Drop）结束后，直接接入下一首曲目 Intro 的接歌技巧，旨在避免完整播放长曲目，保持能量流动。

### 核心概念
*   **适用场景**：无需将当前曲目完整播放至 Outro，在 Drop 高潮段落结束后即可切入下一首。
*   **乐句结构要求**：前一首曲目的 Drop 部分建议包含 3 个乐句或以上。这能确保在 Drop 完整播放 1 到 2 个乐句后，仍有足够的空间平稳接入新曲目的 Intro。

### 操作步骤
1.  **定位前曲 Drop**：播放第一首课程示例曲目，定位至 Drop 段落。
2.  **设定接入点**：在 Drop 的第二乐句开始处，准备接入第二首示例曲目的 Intro CUE 点。
3.  **执行混音**：在第二首曲目的 Drop 段落第三个乐句开始处，准备接入第三首示例曲目的 Intro CUE 点。
4.  **循环操作**：依此类推，利用 Drop 的尾部乐句与下一首 Intro 的起始乐句进行对拍和混音。
