本集讲解 Filter 滤波器混音法，通过低通滤波器（LPF）控制后手曲目接入，替代传统音量推子推入，实现平滑过渡。

### 核心概念
*   **Filter 替代 Channel Fader**：利用 Filter 旋钮的右旋调节替代音量推子（Channel Fader）的缓慢推入，使混音效果更多元。
*   **操作逻辑**：先通过 LPF 隐藏后手曲目声音，快速推起音量推子，再缓慢右旋 Filter 接入声音，最后结合 EQ 进行常规混音。

### 操作步骤
1.  **准备 Filter**：在前手曲目乐句结束、准备进行 EQ 调整时，将后手曲目的 Filter 旋钮左旋到底，设置为低通滤波器（LPF）状态。
2.  **快速推起音量**：在合适时机，将后手曲目（如课程示例 *Booty Bounce*）的音量推子快速推至顶部。由于 EQ 及 Filter 的滤波设置，此时后手曲目声音几乎不可闻。
3.  **右旋 Filter 接入**：缓慢右旋后手曲目的 Filter 旋钮，直至 12 点钟位置（全开）。此过程课程建议持续约 4 个小节。
4.  **EQ 混音收尾**：Filter 接入完成后，依照 EQ 均衡器混音手法继续调整频率平衡。

### 撤出技巧
*   **Filter 撤出法**：在前手曲目（如课程示例 *Sex on Fire*）撤出时，可将 Filter 左旋至 LPF 或右旋至高通滤波器（HPF），配合音量推子拉下进行淡出。
*   **灵活组合**：实际混音中，Filter 打法及与 EQ 的配合可根据曲目音效灵活调整，无固定标准。
