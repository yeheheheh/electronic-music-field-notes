本集讲解电子舞曲中的时间结构单位（拍、小节、乐句）及其在 DJ 软件中的可视化呈现，并演示基础的数拍方法。

### 核心概念

*   **拍 (Beat)**：乐曲时间维度的基本单位。在电子舞曲最常用的 4/4 拍中，以四分音符为一拍，四拍组成一小节。
*   **小节 (Bar/Measure)**：由四拍组成。
*   **乐句 (Phrase)**：通常以 8 个小节为一个乐句。乐句包含基本的旋律和节奏型，是乐曲的核心结构单元。相邻乐句间通常会有元素变化以维持听感新鲜度。
*   **乐段 (Section)**：由若干个乐句组成，进而构成整首舞曲。例如 Progressive 风格常以乐句为单位进行渐进发展。

### 软件可视化 (Rekordbox)

在 Rekordbox 中，经过分析的曲目波形图上通过竖线标识时间结构：

*   **小节线**：带有上下红色小三角形的白色竖线，标识每一小节的起始位置。
*   **拍线**：位于小节线之间的浅灰色竖线，标识每一小节的拍点（每小节 4 条）。
*   **位置计数器**：波形图上方的蓝色数字显示当前播放位置。
    *   第一位数字：当前小节数。
    *   第二位数字：当前小节内的第几拍。

### 数拍操作

数拍（打拍子）是 DJ 必备的基础技能，用于对齐节奏和结构。

1.  **基本周期**：以一个小节（4 拍）为一个计数周期。
2.  **计数格式**：第一位数字为小节序号，后三位为小节内的拍数（2、3、4）。
    *   示例：`1 2 3 4` -> `2 2 3 4` -> `3 2 3 4` -> `4 2 3 4`。
3.  **乐句周期**：以 8 个小节（一个乐句）为大周期进行连续计数。
    *   示例：`5 2 3 4` -> `6 2 3 4` -> `7 2 3 4` -> `8 2 3 4`。
4.  **观察要点**：在播放曲目时同步数拍，观察每过 8 个小节（一个乐句）时，乐曲结构或元素发生的变化。
