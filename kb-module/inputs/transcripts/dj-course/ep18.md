本集介绍一套针对初学者的 Hot CUE 快速设置流程，用固定的颜色编码与布局规则，结合 Beat Jump 功能，实现曲目结构的可视化与高效接歌。

## 核心概念：颜色编码与布局规则

课程建议采用以下颜色与位置编码体系，以统一曲目结构标记（注：Hot CUE 颜色由用户自定义，以下为课程建议方案，非行业标准）：

**颜色标记建议**
*   **绿色系（Intro / Outro）**：浅绿色代表仅含鼓组的 Intro/Outro；深绿色代表含旋律的 Intro/Outro。
*   **蓝色系（Breakdown - 乐器）**：亮蓝色代表突出悦耳的乐器旋律；深蓝色代表普通乐器旋律。
*   **紫色/粉色系（Breakdown - 人声）**：亮粉色代表突出悦耳的人声演唱；紫色代表普通人声。
*   **黄色**：Build-up。
*   **橙色**：Pre-drop 或 Build-up。
*   **红色**：Drop。

**布局规则（8 个 Hot CUE 位）**
*   **A 点**：默认设置 Intro。
*   **B 点**：默认设置 Breakdown。
*   **C 点**：默认设置 Build-up。
*   **D 点**：默认设置 Drop。
*   **E / F / G 点**：自由设置，常用于第二段 Breakdown、Drop 或 Pre-drop 等特色片段。
*   **H 点**：默认设置 Outro。

## 辅助功能：Beat Jump 与 Quantize

在设置 CUE 点前，需掌握以下功能以提升效率：

*   **Beat Jump（跳拍）**：
    *   按下 `Beat Jump` 按钮开启功能。
    *   打击垫对应跳跃拍数：1、2、4、8 拍（前/后）。
    *   按住 `Shift` 键切换页面，对应跳跃 16、32、64、128 拍。
    *   常用跳跃量：32 拍（8 小节/1 个乐句）和 64 拍（16 小节/2 个乐句）。
*   **Quantize（量化）**：
    *   点亮 BPM 圆环旁的 `Quantize` 按钮。
    *   作用：确保 CUE 点准确吸附在小节线或拍子上，避免节奏偏差。

## 操作步骤：八步设置流程

1.  **设置 Intro (Hot CUE A)**
    *   定位至曲目第一拍（第一根小节线）。
    *   **注意**：若 Rekordbox 分析的小节划分不准（如未对齐第一个重拍），需进入 BPM 校准标签页，将指针移至第一个重拍处，点击红白竖线按钮重新校准小节线。
    *   确保 `Quantize` 开启，按下 `Hot CUE A`。

2.  **设置 Drop (Hot CUE D)**
    *   通常在曲目前 1/3 处，寻找紧接较窄波形后的一长段宽而不规则的波形。
    *   使用 `Beat Jump` 移动至该位置试听确认。
    *   按下 `Hot CUE D`。

3.  **设置 Breakdown (Hot CUE B)**
    *   通常在 Intro 结束后波形突然收窄处。
    *   将 CUE 点设置在旋律乐器或人声开始演奏的那一拍。
    *   按下 `Hot CUE B`。

4.  **设置 Build-up (Hot CUE C)**
    *   通常位于 Drop 前约 8 个小节。
    *   移动至该位置，确认是否有鼓点变密集、加入 Risers 等特征。
    *   若有，按下 `Hot CUE C`；若无，可留空。

5.  **设置 Outro (Hot CUE H)**
    *   通常位于乐曲结束前 8–16 小节（1–2 个乐句），特征为淡化主旋律/人声，仅保留纯粹鼓组。
    *   确认位置后按下 `Hot CUE H`。
    *   **特殊情况**：若无完整 Outro，可将最后两个乐句设为 `Hot CUE H` 并标记相应颜色（如人声粉、Drop 红），或留空。

6.  **设置 E / F / G 点**
    *   根据需求自由设置，如第二段 Breakdown、Drop 或 Pre-drop 等特色片段。

7.  **标记颜色**
    *   根据前述颜色规则，为已设置的 Hot CUE 分配颜色。
    *   **灵活调整**：若曲目结构不典型（如无 Intro 直接进入 Breakdown），可将 `Hot CUE A` 设为蓝色 Breakdown 或留空。

8.  **设置 Memory CUE**
    *   作为乐曲开始播放点，课程建议设置在每个 Hot CUE 前 16 小节（2 个乐句）处。
    *   乐曲中其他需要标记的点也可设置 Memory CUE。
