# 电音档案 / Electronic Music Field Notes

一个以「制作课 + 知识库」为双核心的电子音乐学习站。制作课按真实做歌流程推进，知识库负责查原理、找关系、回源头；两者共用同一套知识源与合成音频示例。

- **制作课**：8 个阶段、22 节短课，从工程模板做到导出成曲。每课有产出、完成标准、前置课与相关知识库链接。
- **知识库**：1205 个条目、144 个知识文档、1356 个检索分块；支持全库检索、风格图谱、大族/条目/文档详情。
- **练习 / 实验室**：风格听辨、BPM 估速、七组音色实时开关。
- **声音**：所有试听由 Web Audio 实时合成，不使用原曲录音。

完整的模块划分、页面结构、课程模型与关联方式见 [docs/information-architecture.md](docs/information-architecture.md)。第一次使用建议先读 **[docs/user-guide.md](docs/user-guide.md)（阅读与使用指南）**：三种打开方式、网页操作手册、知识库阅读方法、Agent 接入与 FAQ。

## 视觉与交互语言

视觉方向是 **Club Rig / Soundsystem**：把页面当成一套扩声系统与一张 Rave 传单，而不是通用的「深色卡片网格」。

- **色彩是信号，不是装饰**：焦油黑 `#060607` 打底；钠灯琥珀 `#ffb000` 只表示「当前位置 / 主操作 / 已完成」；激光洋红 `#ff2e63` 只表示「下一课 / 正在播放 / 需要修正」；信号冰蓝 `#2fd8ff` 只表示「参考信息 / 独奏」。大族的四个色相按音域从低到高排列（暖→冷），并且只出现在 2px 边线、圆点与电平帽上，不再铺满整块表面。
- **字体与阅读尺度**：Bahnschrift 窄体承担展示标题与大号阶段编号；正文使用系统无衬线，**17px / 行高 1.86**，段落宽度限制在 62–66 字符；Cascadia Mono 承担 BPM、阶段、时间码与快捷键。数据一律使用等宽数字（`tabular-nums`）。标题分四级：页头 h1（约 2.7rem）→ 章节 h2（约 2.2rem，带编号）→ 区块标签（14px）→ 正文（17px），每一级在字号与字重上都不重叠。
- **章节边界**：每个章节以「编号 + 琥珀短线 + 标题」开头，区块之间用 1px 实线加 56–88px 留白分隔；课时页把内容切成 `01 概念 → 02 先听 → 03 动手 → 04 自检 → 05 回查` 五个带编号的块，读到哪里一目了然。
- **结构语法**：一小节 = 16 格。页头下方是一条 16 分格的 **transport 标尺**，播放时激光色播放头随音频推进；课程进度是一条 22 格、按 8 阶段分组的步进尺，每格可直接点击跳课；课时的完成状态、练习的对错、实验室的七层开关都复用同一套「格 / 通道」语义。
- **图标**：取自硬件而非通用线性图标集 —— 步进序列、黑胶、信号图、波形、推子组。
- **动效**：只保留与声音有关的运动。页头 12 段电平表读取主总线真实 FFT 数据（`AnalyserNode`），静音时归零；播放头、鼓机播放头与指示灯都按当前 BPM 换算节拍长度。页面切换、悬停与筛选使用 step 曲线（`cubic-bezier(1,0,0,1)`）而不是缓动，读起来像切片而不像呼吸。
- **操作反馈**：标记完成前先勾选自检清单，按钮上实时显示「自检 2/3」；完成后写入进度、更新页头胶囊并弹出带「下一课」的提示。课时页底部固定操作条让上一课、完成、下一课始终可达。

## 使用逻辑

页面按「一个目标一个入口」组织，避免同一件事出现两种做法：

- **学习路线可读成一条阶梯**：课程页顶部是 8 个阶段块，上方用三条难度带标出 `基础（00–02）→ 进阶（03–05）→ 完成（06–07）`；每个阶段块显示编号、短名、完成数与 22 格课时刻度，刻度可直接点击跳课。
- **每个阶段都写明三件事**：`进入`（需要先具备什么）、`知识点`（本阶段覆盖的概念，全部链到知识库）、`验收`（做到什么算过关）。当前 8 个阶段共 45 个知识点，全部指向真实条目或文档。
- **页头只有一处主操作**：每个内页顶部是紧凑页头（编号 / 标题 / 一句说明 / 关键数字 / 一个主按钮），不再每页重复「大标语 + 长解释」。
- **首页只保留一个 Hero**：鼓机试听与「开始 / 继续第一课」合并为一个动作；八阶段用紧凑 tracklist 呈现，不再与课程地图重复展开。
- **课程地图可直接跳课**：阶段块内的刻度每格对应一课；「只看未完成」会隐藏已完成阶段，减少滚动。
- **课时页只有一个任务链**：产出与交付物合并成一条 brief；五个编号区块固定「概念 → 先听 → 动手 → 自检 → 回查」；自检清单可勾选并驱动完成按钮。
- **练习与实验室支持键盘**：练习按 `1`–`4` 作答、`空格` 重听、`回车` 下一题；实验室按 `1`–`7` 开关图层、`S` 独奏。


项目现在有两种使用方式：

- **网页展示层**：`index.html`，适合人类阅读、学习与动手。
- **Agent 知识库模块**：`kb-module/`，可独立构建，提供 CLI、MCP stdio 与 HTTP API，详见 [kb-module/README.md](kb-module/README.md)。

## 怎么打开

直接双击 `index.html` 即可，不需要安装依赖或联网。数据以 JS 文件加载，支持 `file://` 打开。

也可以在项目根目录启动本地服务器：

```bash
node scripts/serve.mjs
# 打开 http://127.0.0.1:5501/
```

建议使用较新的 Chrome / Edge。页面适配了桌面、平板和手机，并尊重 `prefers-reduced-motion`。浏览器默认不允许自动播放，点击任意“播放 / 试听”按钮后声音才会启动；页头右侧可以随时静音。

## 学习逻辑

课程不是知识库的目录，而是一条制作路径。顺序按真实工作流而不是学科分类安排：

```text
工程与信号链 → 鼓组与律动 → 低频与 Bass → 和弦与情绪
→ 旋律与音色设计 → 编曲与能量 → 混音与空间 → 完成一首歌
```

每课的数据模型包含：

| 字段 | 作用 |
| --- | --- |
| `outcome` | 学完这一课能做到什么 |
| `deliverable` | 这一课要在 DAW 里留下的具体产物 |
| `prerequisites` | 前置课；缺少时课时页会提示先补哪一课 |
| `goals` | 课末自检清单 |

阶段层（`chapters[]`）另有四个字段，用来描述进阶关系：

| 字段 | 作用 |
| --- | --- |
| `tier` | 难度带：`基础` / `进阶` / `完成`，决定路线带的分组 |
| `entry` | 进入这一阶段前必须具备的能力 |
| `knowledge` | 本阶段知识点数组（`{ label, kb }`），`kb` 指向真实条目/文档 |
| `exit` | 阶段验收：做到什么算过关 |

课时内的其他字段：

| 字段 | 作用 |
| --- | --- |
| `concept` / `keyTerms` | 最小学理，够用就停 |
| `widget` | 站内可播放/可操作的示例，先建立听感 |
| `task` | 可以立刻在 DAW 或站内完成的动作 |
| `kbLinks` | 相关知识库条目/文档，用于回查原理 |
| `links` | 延伸阅读或工具入口 |

知识库在这里承担四件事：

1. **补原理**：课上的名词都能点回条目或文档，而不是停在口号。
2. **定顺序**：前置关系来自制作依赖（没有鼓组就不做低频让位，没有音色就不做混音），课时页会把缺失的前置课标出来。
3. **给验收**：每课的产出与自检清单让“学完了”变成“做出来了”。
4. **反向找课**：从知识库条目/文档或全库检索结果，都能看到“在课程中学习”。

## 双模块与关联方式

**制作课**（`data/course.js`）是编排层：每课声明产出、前置课、互动类型 `widget` 与相关知识库 `kbLinks`。**知识库**（`kb-module/dist` → `data/web.js`）是数据层，提供条目、文档、关系与检索。

- 课程 → 知识库：课时页把 `kbLinks` 渲染为条目/大族/文档链接；课时末尾还可继续全库检索。
- 知识库 → 课程：条目页和文档页显示“在课程中学习”；风格文档通过 `metadata.entryId`、大族文档通过 `metadata.familyId` 建立别名映射，所以 `g-1581` 也能找到关联到 `style:bigroom-house` 的制作课。
- 检索 → 课程：全库检索用 `searchLessons(query)` 同时匹配课时标题、概念、关键词与 `kbLinks` 标签，显示“相关课程”面板。
- 前置课 → 学习路径：课时页读取 `prerequisites`，把还没完成的先修课标出来并给出直达链接；不硬锁课，但顺序有明确依据。
- 练习/实验室 → 课程：练习结果建议回到相关课时；课程复用同一个 Web Audio 引擎与七组音色定义。

核心流程：

1. **第一次来**：首页 → 开始第一课 → 制作课地图 → 课时 → 播放示例 → 在 DAW 完成任务 → 对照交付物与自检清单 → 底部操作条标记完成 → 下一课。
2. **带着问题查**：知识库 → 搜索/图谱 → 条目/文档 → 在课程中学习 → 回到对应课时。
3. **卡住时补前置**：课时页前置课提示 → 回到先修课 → 完成后再继续。
4. **复习**：制作课地图进度 → 已完成课时 → 重听示例 / 重做任务；或搜索 → 相关课程。

## 声音与学习功能

- **首页单小节鼓机**：三行八步的 Kick / Clap / Hat，可直接改节奏并播放；播放头与音频同步，作为进入制作课的第一动作。
- **22 节制作课**：每课至少包含节拍器、8 步鼓机、对比试听、分层实验室、结构播放器或和弦试听中的一种，并配一个明确产出。
- **十种风格试听**：Bigroom House、Electro House、Deep House、Uplifting Trance、Techno、Trap、Future Bass、US Dubstep、Hardstyle、Future Rave。每个都是 2 小节循环，使用合成 Kick、Bass、和弦、Lead、FX 等搭出该风格的骨架。
- **音色实验室**：七组（打击乐 / 贝斯 / 和弦 / 人声 / 主奏 / 氛围 / 音效）可实时开关，BPM 可在 100–160 之间调整；适合先关掉所有层，再一层层加回来。
- **八段结构播放器**：16 小节、约 30 秒的结构示例，依次走过 Intro、Breakdown、Build-up、Drop、第二次间奏、第二次渐进、第二次 Drop、Outro，并高亮当前段落。
- **听辨练习**：风格四选一与 BPM 估速；带得分、连对与即时反馈。片段都是合成循环。
- **全局声音控制**：页头声音开关、底部播放条、进度条与音量；切换页面时播放状态保持，可随时停止。
- **不使用音频文件**：所有声音由 `audio.js` 通过 Web Audio API 实时合成，没有原曲录音，也没有版权音频下载。

首次播放需要用户点击（浏览器自动播放策略）。如果浏览器不支持 Web Audio，按钮会提示不可用，但文字、图谱与检索仍然正常工作。

## 重新生成数据

模块的自包含输入在 `kb-module/inputs/`：

- `taxonomy.md`：分类库 Markdown。
- `curated.json`：精编内容（含首页文案与入口）。
- `transcripts/`：转写资料。
- `source-map.json`：来源、作者、链接与许可说明。

修改输入后运行：

```bash
# 只构建 Agent 模块
node kb-module/bin/kb.mjs build

# 或：构建模块并同步网页数据
node scripts/build-data.mjs
```

`scripts/build-data.mjs` 会先生成 `kb-module/dist/`，再生成网页使用的 `data/kb.json`、`data/kb.js`、`data/curated.js`、`data/web.js` 与 `data/genres.csv`。网页不再单独维护解析逻辑。

课程内容 `data/course.js` 是手工编排的编辑层，不由模块生成；修改课时、任务、产出或 `kbLinks` 后刷新页面即可，不需要重新构建知识库。

解析规则：

- 按 Markdown 标题层级建立结构树；`前言` / `大纲` 不计入条目。
- 识别 `上位/下位`、`上/下`、`Related To`、`A.K.A./AKA`。
- 从正文提取 BPM、例曲、别名和结构下级。
- `待完善`、`交叉引用`、`待归档` 保留原始状态，不替原文补写。
- 条目的 `id` 基于原文行号，重新排版原文后链接可能变化。

## Agent 接入

模块提供三种调用方式：

| 方式 | 启动/入口 | 适合 |
| --- | --- | --- |
| MCP stdio | `node kb-module/bin/mcp-server.mjs --dist kb-module/dist` | Claude Desktop、Qoder 等支持 MCP 的 Agent |
| CLI | `node kb-module/bin/kb.mjs search ...` | shell 工具、自研 Agent |
| HTTP | `node kb-module/bin/kb.mjs serve --port 8787` | LangChain、函数调用、跨进程调用 |

MCP 工具：`kb_search`、`kb_context`、`kb_get`、`kb_families`、`kb_manifest`。配置示例、OpenAI 工具定义与系统提示词在 `kb-module/agent/`，完整接口契约见 [kb-module/README.md](kb-module/README.md)。

网页与 Agent 共用同一份知识库产物：网页加载模块生成的 `data/web.js`，在浏览器内做同源 BM25 检索；Agent 则直接读取 `kb-module/dist/`。两者不是两套内容。

网页的工具提示、页头快速搜索浮层使用本地引入的 [Floating UI](vendor/floating-ui-1.8.0-umd/LICENSE) 做定位，包含自动翻转、边界避让、箭头定位与滚动跟随；不依赖 CDN。

## 已知限制

- BPM 只覆盖原文档明确写出数字的 134 个条目；没有数字不等于没有速度特征。
- 原文档有 90 个内容很少的条目，其中部分只是指向其他板块的交叉引用。
- 有 72 组同名或近名条目，分布在不同大族；详情页的面包屑与所属大族用于区分。
- 分类是有立场的民间整理，不是音乐产业的标准答案；同一声音在不同城市、厂牌、社群会有不同叫法。
- 例曲只提供文字索引，不提供音频；版权归原作者。请把本库当作学习与研究资料，不要当作音乐下载站。
- 试听片段是合成示例，不是原曲；它用于展示节奏、音色与结构差异，不能替代原曲欣赏。人声层用合成器模拟，不是真人录音。
- 音频依赖 Web Audio；老旧浏览器或禁用音频的浏览器只能使用文字与检索功能。
- 制作课不会替你操作 DAW：任务与交付物写在页面里，实际工程需要你在自己的软件里完成。
- 课程进度保存在浏览器 `localStorage`（键：`em-course-progress-v1`），没有账号或后端同步；换浏览器/清缓存会丢失。加载时会过滤已不存在的旧课时 ID。
- 课程是编辑内容，不自动从知识库生成；知识库更新后，若新增/改名了课程引用的条目或文档，需要同步检查 `data/course.js` 的 `kbLinks`。
